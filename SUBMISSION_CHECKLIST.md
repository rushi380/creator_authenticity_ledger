### Privacy Behavior Evidence

The privacy behavior is **architecturally enforced**, not cosmetic:

- Private metrics are supplied as **witness callbacks** (`src/utils/contract.ts` → `createWitnessProvider()`)
- Verification runs the **real on-chain pipeline** (`src/utils/onchain.ts`): local circuit execution → ZK proof → wallet balancing/signing → submission → finalization
- After verification, the UI shows **redacted blocks** for all private values — they are never stored in component state after submission
- The Brand portal shows `████████████ — Protected by Midnight ZK privacy`
- The `disclose()` primitive in the Compact contract (`contracts/creator_authenticity.compact`) is the only path by which any value reaches the ledger
