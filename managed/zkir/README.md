# zkir/

ZK intermediate representation files generated by the Compact compiler.

After running `compact compile`, this directory will contain:
- `proveAuthenticity.zkir`   — ZK circuit for the main authenticity proof
- `resetVerification.zkir`   — ZK circuit for the reset operation

These files are loaded by the Midnight proof server at runtime.
Run `npm run copy:artifacts` after compilation to populate `public/zkir/`.
