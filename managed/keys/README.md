# keys/

Prover and verifier keys generated by the Compact compiler.

After running `compact compile`, this directory will contain:
- `proveAuthenticity.pk`   — prover key for the authenticity circuit
- `proveAuthenticity.vk`   — verifier key for the authenticity circuit
- `resetVerification.pk`   — prover key for the reset circuit
- `resetVerification.vk`   — verifier key for the reset circuit

These files are served from `public/keys/` by the frontend.
Run `npm run copy:artifacts` after compilation to populate `public/keys/`.
