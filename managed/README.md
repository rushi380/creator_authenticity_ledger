# managed/ — Generated Compact Artifacts

This directory contains the compiled output of the Compact smart contract.

## What lives here

| File/Dir | Contents |
|---|---|
| `keys/` | Prover key (`.pk`) and verifier key (`.vk`) |
| `zkir/` | ZK intermediate representation (`.zkir`) |
| `*.js` | TypeScript/JS bindings generated by the Compact compiler |
| `*.d.ts` | TypeScript declarations for the contract interface |

## How to regenerate

The Compact compiler must be installed (Linux/WSL/macOS):

```bash
# Install Compact toolchain
curl --proto '=https' --tlsv1.2 -LsSf \
  https://github.com/midnightntwrk/compact/releases/latest/download/compact-installer.sh | sh

# Restart your shell, then compile:
compact compile contracts/creator_authenticity.compact ./managed

# Copy artifacts to public/ for the frontend:
npm run copy:artifacts
```

## Why this directory is committed

The `managed/` directory is committed so that:
- CI can run tests without the Compact toolchain installed
- The frontend can reference artifact paths during development
- Reviewers can inspect the generated circuit interface

**The placeholder files below are replaced by real artifacts after compilation.**

## Re-compile when

- `contracts/creator_authenticity.compact` is modified
- Compact language version is upgraded
- Circuit logic changes
